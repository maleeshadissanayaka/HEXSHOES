# 3–5 minute demo

1. Open Home and Shop; show the responsive catalog and product detail.
2. Sign in; show persisted profile, wishlist, and cart.
3. Run image Visual Search, then add text to demonstrate multimodal fusion.
4. Open a result and show real Similar Styles.
5. Show recommendations and explain their real evidence or honest cold start.
6. Ask HEX Assistant for a trail shoe and to compare Runner versus Trail.
7. Ask it to save Trail; show no mutation before Confirm, then confirm and show synchronized state.
8. Mention eight-query retrieval evaluation and its same-catalog limitation—never production accuracy.
