# Portfolio claim audit

## Implemented

React/TypeScript storefront; Express/TypeScript API; Firebase Auth, server token verification and Firestore account persistence; FastAPI/PyTorch/OpenCLIP; normalized embeddings and cosine retrieval; image/text/60:40 multimodal search; Similar Styles; transparent content-based recommendations; deterministic grounded shopping agent with signed confirmations; retrieval evaluation, recommendation-mechanics validation, similarity analysis, PCA; automated tests and local Chromium verification.

## Planned or absent

No public deployment, production traffic/scale or SLA; payments, checkout, inventory, orders, delivery or return integration; sales/revenue/conversion/retention analytics; collaborative filtering, forecasting or customer segmentation; production monitoring or distributed rate limiting; LLM; or broad recommendation-accuracy claim. The small manually labeled relevance set is not a holdout production benchmark.
