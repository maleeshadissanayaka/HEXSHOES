# Portfolio claim guidance

## Safe claims

- Built and deployed a full-stack AI-powered footwear ecommerce demonstration platform.
- Implemented OpenCLIP text, image, and multimodal semantic retrieval in a shared embedding space.
- Deployed React, Express, and FastAPI across Vercel and Railway with Firebase Authentication and Firestore.
- Implemented persistent authenticated profiles, cart state, and saved styles.
- Built Similar Styles and content-based recommendations grounded in canonical catalog products.
- Implemented a deterministic grounded shopping agent with explicit intent routing and confirmation-gated mutations.
- Designed a reproducible retrieval evaluation pipeline with manually labeled same-catalog queries.
- Used normalized 512-dimensional OpenCLIP embeddings and cosine similarity over a four-product demonstration index.

## Claims requiring qualification

- Report P@1 1.0, P@3 0.333333, Recall@3 1.0, MRR 1.0, and NDCG@3 1.0 only as results from the eight-query same-catalog demo evaluation.
- Describe recommendations as content-based wishlist/cart recommendations, not broad personalization quality.
- Describe deployed AI as CPU-hosted inference with potential cold starts.
- Describe the storefront as a demonstration; checkout, payments, inventory, shipping, and orders are absent.

## Do not claim

- An LLM-powered or generative agent.
- Production-grade ML accuracy, production benchmark quality, or broad generalization.
- Enterprise scale, millions of products, high traffic, an SLA, or commercial production readiness.
- Vector database usage, collaborative filtering, or GPU inference.
- Cosine similarity as probability or confidence.
- Live inventory, fulfilled orders, revenue, conversion, retention, or customer-behavior outcomes.

Preferred language: **deterministic grounded shopping agent**, **OpenCLIP semantic retrieval**, **cosine similarity score**, **small four-product demonstration catalog**, **same-catalog labeled demo evaluation**, and **CPU-hosted model inference**.
