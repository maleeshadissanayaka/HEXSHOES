# Portfolio screenshot plan

Capture from `https://hexshoes.vercel.app` using consistent desktop and mobile viewports.

## Recommended set

1. Homepage hero and primary navigation.
2. Authentication or account view with personal information obscured.
3. Shop catalog and product detail.
4. Text search with a grounded ranked result.
5. Image visual-search input and results.
6. Multimodal image-and-text result state.
7. Product page Similar Styles section.
8. Personalized recommendation section with a grounded reason.
9. HEX Assistant search or comparison response.
10. HEX Assistant pending confirmation before mutation.
11. Synchronized wishlist or cart after confirmation.
12. Architecture diagram from the README or a documentation presentation.

Use only the strongest non-duplicative images. A compact sequence should communicate storefront quality, authenticated persistence, semantic retrieval, recommendations, agent safety, and deployed architecture.

Use demo account content only. Crop browser identity and obscure emails, UIDs, tokens, confirmation tokens, credentials, environment values, and private Firestore records. Do not show similarity scores as percentages, probabilities, or confidence. Verification captures remain untracked unless explicitly selected for publication.
