# Evaluation Summary

## A. Retrieval relevance evaluation

Eight text queries were manually labeled from the identity, category, and description of the real four-product catalog. Each query has one binary-relevant product. Rankings were generated by the real OpenCLIP text encoder and persisted catalog image index.

At `K=3`:

| Metric | Result |
| --- | ---: |
| Precision@1 | 1.000000 |
| Precision@3 | 0.333333 |
| Recall@3 | 1.000000 |
| MRR | 1.000000 |
| NDCG@3 | 1.000000 |

Every labeled product ranked first for its two category-grounded query variants. Precision@3 is one third because every query has exactly one labeled relevant item and three returned items.

These are demonstration metrics, not production metrics. The labels are small, manually created, and derived from the same four-product demo catalog rather than an independent holdout set. They are not evidence of broad generalization.

## B. Recommendation system sanity validation

No genuine recommendation relevance or feedback labels exist, so recommendation Precision, Recall, MRR, and NDCG are not reported. Algorithm test scenarios—not user records—confirmed:

- current-product exclusion from Similar Styles;
- wishlist/cart interacted-item exclusion;
- deterministic repeated output;
- reason codes grounded in the interaction that supplied evidence;
- catalog-valid product IDs only;
- deterministic new-first cold-start discovery.

The scenario uses wishlist weight `1.0` and cart weight `1.3`. Production cart weights use `1.0 + 0.15` per extra quantity, capped at `1.45`.

## Embedding analysis

The strongest non-self cosine pair is `hx-01` / `hx-02` (`0.605868058`). The weakest is `hx-02` / `hx-03` (`0.372952055`). PCA component 1 explains `46.31%` and component 2 explains `29.03%`, or `75.34%` together. This is an exploratory 2D projection of 512D CLIP embeddings; four products are insufficient for stable cluster interpretation, so clustering was skipped.

## Interaction analytics

Live Firestore analytics are generated only on demand and are not committed because account activity is private and changes over time. The script prints aggregate profile-document, wishlist-item, cart-item, and product-level counts without UIDs, emails, names, tokens, or raw documents.
